# Laboratório de Gerenciamento de Código-Fonte

Repositório modelo para a prática de **Git e GitHub** em duplas: commit, push, pull, conflitos, branches, Pull Request e merge.

---

## O projeto

Uma landing page simples, feita com HTML, CSS e JavaScript puros — sem framework e sem etapa de build. O conteúdo é propositalmente pequeno: o objetivo não é a página, e sim **o que acontece com o histórico** enquanto duas pessoas a alteram ao mesmo tempo.

```
├── index.html       página principal
├── style.css        estilos da página
├── script.js        scripts (começa vazio)
├── README.md        este arquivo
├── .gitignore       arquivos que o Git deve ignorar
└── .gitattributes   padronização das quebras de linha
```

## Como abrir a página

Não é preciso instalar nada além do navegador:

- **Opção 1:** dê duplo clique no `index.html`.
- **Opção 2:** no VS Code, instale a extensão **Live Server**, clique com o botão direito no `index.html` e escolha **Open with Live Server**. A página se atualiza sozinha a cada vez que você salva um arquivo.

## Antes de começar

- Os comentários dentro do `index.html` e do `style.css` indicam **qual parte do roteiro altera cada trecho**. Não os apague antes de chegar à parte correspondente.
- O `style.css` já contém os estilos dos elementos que vocês vão criar (menu, parágrafo de descrição). Quando o elemento aparecer no HTML, o estilo se aplica sozinho.
- Use sempre o seu **próprio usuário do GitHub**. Os commits são a evidência da participação de cada integrante.
